    Setup

    # Install the SDK if needed
pip install anthropic

# Set your API key
export ANTHROPIC_API_KEY=sk-ant-...

    Count tokens in text (precise, via API)

    python tracker.py count "Your message here"
python tracker.py count "Your message" --model claude-sonnet-5-5
python tracker.py count "Message" --log   # also saves to log

    Count tokens in a file

    python tracker.py count -f document.txt
python tracker.py count -f prompt.md --log

    Log a completed exchange

    python tracker.py log 1842 347 -n "chat session"
python tracker.py log 5120 1200 --model claude-sonnet-5-5

    View statistics

    python tracker.py stats
python tracker.py prices
